# techcorp-cloud-lab
Enterprise Cloud Infrastructure Lab - Azure, Linux, Storage, Networking

TechCorp Cloud Infrastructure Lab
> A hands-on enterprise cloud infrastructure project demonstrating
> real-world Technical Support Engineer skills
Project Overview
Simulated a complete enterprise cloud migration for "TechCorp Inc"
using Microsoft Azure, covering storage, networking, Linux administration,
backup/recovery, and API troubleshooting.
What I Built

Week 1 - Infrastructure
•	✅ Azure VNet with 2 subnets and NSG rules
•	✅ Private DNS zone with autoregistration
•	✅ 2 Ubuntu Linux VMs
•	✅ NFS server/client configuration
•	✅ Samba (SMB/CIFS) file sharing
•	✅ Azure Blob Storage with soft delete
•	✅ Azure Backup with Recovery Services Vault
•	✅ VM snapshots and disk management
Week 2 - Debugging & Protocols
•	✅ Network packet capture with tcpdump
•	✅ Wireshark traffic analysis
•	✅ System call tracing with strace
•	✅ API troubleshooting with Postman
